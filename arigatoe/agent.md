# Arigatoe — Handoff State

## Project status

Arigatoe is a standalone TypeScript/Vite canvas prototype located in this directory. It is intentionally independent from the other `C:\git\prototypes` projects.

The entire `arigatoe/` directory is currently untracked by Git (`?? ./` when checked from this directory). Nothing has been committed yet.

## Toolchain and commands

- Package manager: pnpm 11.19.0
- Runtime: TypeScript 7 + Vite 8
- Build verification most recently passed on 2026-08-28.

Run from `C:\git\prototypes\arigatoe`:

```powershell
pnpm run dev
pnpm run build
pnpm run serve
```

`pnpm run serve` serves `dist/` on port 1234. It is intended only for short local previews; do not leave it running after testing.

## Implementation conventions

- Keep this a client-only canvas game; do not add framework or shared repository infrastructure for ordinary feature work.
- Use `apply_patch` for source and documentation edits.
- Keep Vite image imports in `src/main.ts`; absolute `/src/...` image paths do not work in the production build.
- `dist/` is generated by `pnpm run build`; do not edit it manually.

## Current verification

- `pnpm run build` passes (`tsc --noEmit && vite build`).
- The compiled game was browser-smoke-tested on desktop and at a 390px mobile viewport. Recent tests had no console errors.

# 10 — Corridor and three-door adventure

**Study scope:** v13 door rules below supersede the original v6 odds and zero-start pot. The v6 return estimate below predates room-specific refills/extra clears; see [11](11-room-refills.md) for the current v7 study and progression rules.

**Context packet:** Scatter entry allocates N moves. Each move approaches three doors for 3000 ms, then waits for one choice. Calibrated prize chances are Coin30%, Multiplier4.73%, Stairs15%, Ghost50.27%. The multiplier bag/values and full-round seed are preserved, with less frequent compounding; see [15](15-current-balance.md). Coin is 1.00 × current floor (1–6). Start with the entire settled base round win (already credited), so multipliers apply to the combined base+bonus round pot and stairs add one floor up to x6. Every choice consumes one move. After the final reveal, Return to mansion restores the settled base board; all base wins have finished before entry. There are no Scatter symbols drawn inside the corridor feature.

**Authority:** [bonus.ts](../../src/bonus.ts) contains pure math and exact cent formatting; [bonus-scene.ts](../../src/bonus-scene.ts) renders perspective animation; [main.ts](../../src/main.ts) coordinates controls, counters, credits and return. [Bonus tests](../../tests/bonus.test.mjs) and [full-game study](studies/door-bonus-validation.json) provide evidence.

## Constructed sequence and payout credit

Base chain pays 2.00, already credited. Six moves: x3 (round pot 6.00, gain 4.00) → Coin (+1.00, pot 7.00) → Stairs (floor2, gain0) → floor-two Coin (+2.00, pot9.00) → Ghost (gain0) → x2 (pot18.00, gain9.00). Bonus gains total16.00; the combined Round/Session increment for this paid chain is18.00, not20.00. Entry and Return add nothing. Moves do not increment the base Spins counter.

## Historical v6 study and limitations

100,000 full paid chains, seed 20261101, with historical 57/23.75/14.25/5 symbol odds: gross RTP **9.9003%**, approximate 95% interval **9.1010–10.6996%**, hit rate **63.007%**. Observed 437 door bonuses, 2674 moves and 377,700 cents of door awards. Category counts: Coin 903, Multiplier 663, Stairs 144, Ghost 964. Base and door awards sum to 990,030 cents on 10,000,000 wagered cents. This is a small prototype study with volatile repeated-multiplier tails, not a calibrated 96% result or certification; payout rebalancing was deferred in that snapshot. See [12](12-rtp-balance.md) for the historical calibration; current calibration is in [15](15-current-balance.md).

Reproduce v6 with `npm run simulate -- --rounds=100000 --seed=20261101 --weights=57,23.75,14.25,5 --room-refills=off --keep-scatters=off`. This selects historical odds/paytable, a zero seed and no Mystery. For v12 persistence snapshots, add `--paytable=legacy --bonus-pot=zero --door-odds=legacy` with their original flags/weights. Simulation stores money exactly, serializing cent values as numbers when safe or decimal strings otherwise; statistics use floating point. The base-only 6.09404% study and this 9.9003% v6 study predate current progression; later tails remain poorly sampled.
